Elegí realizar este proyecto de EcoRecicla porque me pareció una buena forma de aplicar los conocimientos que hemos aprendido durante el curso, especialmente en programación, manejo de bases de datos y desarrollo de aplicaciones web.

También elegí el tema del reciclaje porque considero que es un tema importante en la actualidad. Muchas veces se reciclan materiales, pero no se lleva un control de cuánto se recicla, qué materiales se están recolectando o quién está realizando los registros. Por eso quise crear un sistema sencillo que permitiera llevar ese control de una manera organizada.

Además, escogí este proyecto porque me permitía implementar diferentes funciones que quería practicar, como agregar, actualizar y eliminar usuarios, registrar materiales reciclados, utilizar una base de datos relacionada y mostrar estadísticas sobre los materiales reciclados.

Mi intención no fue hacer un sistema demasiado complejo, sino crear una aplicación que pudiera demostrar de manera práctica lo que aprendí durante el curso y que, al mismo tiempo, tuviera una utilidad en una situación real.
